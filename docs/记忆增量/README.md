# 记忆增量（机制细则）

- 每次「记忆:保存」在 `<记忆目录>/记忆增量/YYYY-MM-DD.md` **追加**（同一天多次会话追加同一文件）
- 四字段：`改动 / 决策 / 遗留 / 踩坑`；只写**增量事实**，不抄 AGENTS.md 与主快照已有内容
- 单份 ≤50 行；超限 = 该写主快照了，提示「记忆:合并」
- 记忆文件不进任何 CI/构建；不写密钥/环境变量值
- 口令对照：「提交推送+记忆」= git + 追加当天增量，一次提交推送；「记忆:合并」= 把 ≥5 天增量提炼进主快照并删已合并文件；「记忆:恢复」= 默认增量补读，`全量` 按日期升序读完

## 增量文件模板

```markdown
# 记忆增量 YYYY-MM-DD

- 改动：<file>：<一句话>（原因/对应需求章节）
- 决策：<拍板内容及理由>
- 遗留：<TODO>
- 踩坑：<一句话>
```
