# 记忆增量（机制细则）

- 每次「记忆:保存」在 `docs/记忆增量/YYYY-MM-DD.md` 追加；同一天多次会话追加同一文件。
- 四字段：`改动 / 决策 / 遗留 / 踩坑`；只写增量事实，不重复 `AGENTS.md` 与主快照内容。
- 单份不超过 50 行；超限时提示执行「记忆:合并」。
- 记忆文件不进入 CI/构建，不写密钥或环境变量值。
- 「提交推送+记忆」= Git 操作 + 当天增量，一次提交推送；「记忆:合并」= 把至少 5 天增量提炼进主快照并删除已合并文件；「记忆:恢复」默认补读新增量，`全量` 按日期升序读完。

## 增量文件模板

```markdown
# 记忆增量 YYYY-MM-DD

- 改动：<file>：<一句话>（原因/对应需求章节）
- 决策：<拍板内容及理由>
- 遗留：<TODO>
- 踩坑：<一句话>
```
