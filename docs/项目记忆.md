## 项目快照

个人 agent skill 公开仓（monorepo），双格式分发：

- **pi 原生包**：`package.json` 的 `pi` manifest 指向 `./skills`，用 `pi install git:github.com/selbylei/yoyo-skills@vX.Y.Z` 安装。
- **通用 Agent Skills**：每个 skill 位于 `skills/<name>/SKILL.md`，用 `npx skills add selbylei/yoyo-skills` 安装。

当前 4 个公开 skill：

| skill | 用途 | 环境要求 |
|---|---|---|
| `yoyo-project-memory` | 项目两层记忆同步 | 纯 Markdown 约定 + git |
| `yoyo-gitee-repo` | Gitee 一句话建仓推送 | 各机自备 `~/.gitee-token` |
| `yoyo-codeup-repo` | 阿里云 Codeup 一句话建仓推送 | 各机登记 SSH 公钥 |
| `yoyo-douyin-digest` | 抖音视频转逐字稿笔记 | bash/uv + Chrome 抖音登录态 |

`yoyo-douyin-release-card` 为 ai_ask 项目专属，不进入本公开仓。

## 环境与红线

- 仓内不含凭据、cookies、token 或环境变量值；各 skill 只记录依赖方式。
- 自制 skill 使用 `yoyo-` 前缀。
- 发版直接在 `main` 的目标提交上打 `vX.Y.Z` tag，不建 release 分支。
- 发版流程：commit → tag → `git push origin main --tags`。
- 机器专属路径、版本、地址与配置只写带机器标签的增量，不上提主快照。

## 自测命令

- 校验包元数据：`npm pkg get name version pi`
- 查看 skill 清单：`Get-ChildItem skills -Directory`
- 校验工作树：`git status --short --branch`

## 维护约定

- 主快照只保存稳定事实；会话变化写入 `docs/记忆增量/YYYY-MM-DD.md`。
- 增量累计至少 5 天后，用「记忆:合并」提炼主快照并删除已合并工作区文件。
- 重要 skill 决策同步登记到个人台账；未经明确要求不写入本仓密钥或机器专属信息。
