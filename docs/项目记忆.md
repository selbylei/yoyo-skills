## 项目快照

个人 agent skill 公开仓（monorepo），双格式分发：
- **pi 原生包**：`package.json` 的 `"pi"` manifest（`pi.skills: ["./skills"]`，keyword `pi-package`），`pi install git:github.com/selbylei/yoyo-skills@vX.Y.Z`（`-l` 项目级）
- **通用 Agent Skills**：`skills/<name>/SKILL.md`（agentskills.io 规范），`npx skills add selbylei/yoyo-skills [-a <agent>]`，支持 70+ agent（`-a` 值与安装目录已从 CLI 源码核实，写进 README）

## 环境与红线

- **仓内不含任何凭据/cookies/token**：SKILL.md 只写「各机自备」，缺失时按各 skill 环境要求节补齐
- 自制 skill 一律带 `yoyo-` 前缀（全局 AGENTS.md 规则；登记台账：`~/Documents/project/playground/skills/自建skills清单.md`）
- 发版纪律（2026-10-17 拍板，按正常流程走）：**tag 直接打在 main 的 commit 上，不建 release 分支**；发版 = commit → 打 tag vX.Y.Z → `git push origin main --tags`；安装方升级 = `pi update`（锁 tag 的需重装新 tag）或 `npx skills update`
- Windows 机零拷贝安装（各机自备凭据即可）

## 自测命令

- 本地装包验证：`pi install ./`（在仓根目录）
- skill 清单核对：`npx skills add selbylei/yoyo-skills -l`
- 本地副本对齐（本机维护习惯）：`diff -rq skills/<name> ~/.pi/agent/skills/<name>`（前 3 个 skill 本机有实体副本）

## 维护约定

- skill 改动：先改本机 `~/.pi/agent/skills/<name>/`，要发布的改动同步进本仓 + 打新 tag（台账「维护约定」）
- 重要决策/新 skill 登记：台账 `自建skills清单.md`（playground 仓）
